# 🎓 School Control

O projeto foi criado com o objetivo de praticar desenvolvimento Fullstack, trabalhando frontend moderno, backend simples e integração entre API e interface.

## ⚙️ Stack Utilizada

### Frontend
- HTML5
- CSS3
- JavaScript Vanilla

### Backend
- Node.js
- Express
- Chart.js
- CORS

## ✨ Funcionalidades

### 📊 Dashboard

- Quantidade total de alunos
- Quantidade de meninos e meninas
- Quantidade de turmas
- Gráfico de distribuição por sexo
- Gráfico de faixa etária

### 📝 Cadastro de alunos

O sistema possui formulário completo contendo:

- Nome completo
- Idade
- Sexo
- Turma
- CPF
- RG
- Data de nascimento
- Nome da mãe
- Nome do pai
- Telefone
- E-mail
- Endereço

### 🧾 Cards de alunos

Todos os alunos cadastrados aparecem em cards modernos contendo:

- Nome
- Idade
- Sexo
- Turma

Ao clicar em um card:
- Um modal é aberto
- Todas as informações completas do aluno são exibidas

## 🚀 Como executar o projeto

### 1. Clone o projeto

```bash
git clone https://github.com/AlexMaciel-dev/School_Control.git
```

### 2. Instale as dependências
Entre na pasta backend:

```bash
cd backend
```

Instale

```bash
npm install
```

### 3. Inicie o servidor

```bash
npm start
```

Servidor rodando em: 

```bash
https://localhost:3000
```

### 4. Abra o frontend

Abra o arquivo: 

```bash
frontend/index.html
```

## API

### Buscar alunos

```http
GET /alunos
```

### Cadastrar aluno

```http
POST /alunos
```
